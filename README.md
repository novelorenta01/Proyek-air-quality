# Proyek Analisis Data: Kualitas Udara Beijing (2013-2017)

Proyek ini bertujuan untuk melakukan Exploratory Data Analysis (EDA) terhadap dataset kualitas udara Beijing serta menyajikan insight interaktif melalui dashboard berbasis Streamlit.

---

### Setup Environment - Pipenv

Buka terminal atau *command prompt* di dalam folder proyek Anda, lalu jalankan perintah berikut secara berurutan:

```bash
1. pipenv install -r requirements.txt
2. pipenv install jupyter
3. pipenv shell
4. jupyter notebook 
```

### Run Streamlit APP
``` bash
streamlit run dashboard.py
```
